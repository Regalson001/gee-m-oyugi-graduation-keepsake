
# Gee M. Oyugi — Graduation Keepsake

A premium, responsive graduation tribute website celebrating **Gee M. Oyugi** on **18 November 2026**.

## Project Overview

This project is a personalised digital graduation keepsake designed with a refined editorial aesthetic. It combines elegant typography, champagne-gold accents, deep forest-charcoal backgrounds, portrait photography and subtle interactive effects.

The experience celebrates an important academic milestone through a dedicated tribute, portrait gallery and graduation date display.

## Features

- Personalised graduation hero section
- Custom honouree name and celebration date
- Two personal portrait photographs
- Layered photographic composition
- Personal congratulatory tribute
- Dedicated graduation milestone display
- Responsive mobile navigation
- Smooth scrolling and reveal animations
- Responsive desktop, tablet and mobile layouts
- Reduced-motion accessibility support
- Semantic HTML5 structure
- Custom CSS styling
- Vanilla JavaScript interactions

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts
- Intersection Observer API

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure both portrait photographs are inside the `assets` folder.
4. Open `index.html` using Live Server.
5. View the website in your browser.

## Personalisation

The project intentionally avoids specifying a particular degree or university.

The graduation tribute uses the wording:

**A Proud Academic Milestone**

Celebration date: **18 November 2026**

## Deployment

This project can be hosted using GitHub Pages.

1. Push the project to GitHub.
2. Open the repository's Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch and the root folder.
6. Save your settings.
